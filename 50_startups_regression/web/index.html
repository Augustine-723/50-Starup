📈 Training vs Testing RMSE by Number of Features

訓練集與測試集誤差比較折線圖

透過觀察 Training RMSE（藍色實線）與 Testing RMSE（橘色虛線）之收斂與發散現象，判定模型適配度狀態：

Underfitting

嚴重欠擬合 (k = 1, 2)

當模型僅使用 1 或 2 個特徵時，特徵僅由地理位置虛擬變數組成（State_New York, State_Florida），完全缺乏核心研發支出。

訓練集與測試集 RMSE 高達 35,000 ~ 41,000 美元，且測試集 R² 為負值（-0.56 ~ -0.59），模型嚴重缺乏表達能力（High Bias）。

特徵：State_New York / State_Florida
Optimal

最佳平衡點 (k = 3) 🏆

特徵增加至 3 個時納入核心變數 R&D Spend，測試集 RMSE 驟降至 $7,946.37（全實驗最低），測試集 R² 躍升至 0.9220（全實驗最高）。

模型在保持精簡特徵數的同時，完美捕捉利潤的主導因子，泛化能力達到頂峰。

特徵：R&D Spend + State_Florida + State_NY
Overfitting

微幅過擬合 (k = 4, 5)

陸續納入 Administration 與 Marketing Spend 後，訓練集 RMSE 持續遞減（9,517 → 9,162 → 8,927），但測試集 RMSE 反彈至 9,055 ~ 9,316。

訓練誤差持續降低但泛化測試誤差回升，代表額外變數引入了共線性雜訊，符合標準過擬合特性。

特徵：+ Administration + Marketing Spend
